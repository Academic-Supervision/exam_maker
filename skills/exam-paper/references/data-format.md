# صيغة ملف البيانات

ملف JSON واحد فيه مفتاحان: `meta` و`questions`. مثال كامل يعمل كما هو:
`example/exam-sample.json`.

مسارات الصور نسبية إلى مجلد ملف الـJSON نفسه.

## meta

| المفتاح | مطلوب | المعنى |
|---|---|---|
| `title` | نعم | عنوان الاختبار |
| `subject` | نعم | المادة |
| `grade` | نعم | الصف |
| `school` | لا | الافتراضي «مدارس أجيال المواهب» |
| `department` | لا | سطر صغير تحت اسم المدرسة |
| `term`, `year`, `date`, `duration` | لا | تظهر بطاقةً لكل واحدة إن وُجدت |
| `total_marks` | لا | إن تُركت حُسبت من مجموع `marks`؛ وإن كُتبت وخالفت المجموع ظهر تحذير |
| `dir` | لا | `rtl` (الافتراضي) أو `ltr` لاتجاه الورقة كلها |
| `student_fields` | لا | حقول الطالب؛ الافتراضي الاسم والفصل ورقم الجلوس |
| `instructions` | لا | قائمة تعليمات تظهر في صندوق أعلى الورقة |
| `logo` | لا | مسار شعار بديل |
| `end_note`, `footer` | لا | «انتهت الأسئلة» وعبارة الختام |

## questions

لكل سؤال: `type` و`prompt` و`marks`، وله اختيارياً:

| المفتاح | المعنى |
|---|---|
| `sub` | شرح أصغر تحت نص السؤال (مثلاً ترجمة عربية لتعليمة إنجليزية) |
| `dir` | `ltr` لسؤال إنجليزي داخل ورقة عربية |
| `marker` | `arabic` (أ ب ج د) أو `latin` (A B C D) أو `num` |
| `splittable` | `true` يسمح بقطع السؤال بين صفحتين. الافتراضي `false`، ويصير `true` تلقائياً لقطع القراءة وأسئلة الإنشاء والأسئلة ذات ثماني فقرات فأكثر |

### mcq — اختيار من متعدد

```json
{ "type": "mcq", "marks": 4, "prompt": "اختر الإجابة الصحيحة.",
  "items": [
    { "text": "عاصمة المملكة هي ______.",
      "choices": ["الرياض", "جدة", "الدمام", "أبها"] }
  ] }
```

للفقرة `image` اختياري. والخيارات تُجمع في سطر واحد ما دامت تتسع.

### truefalse — صح وخطأ

```json
{ "type": "truefalse", "marks": 3, "labels": ["√", "×"],
  "items": [ { "text": "الفاعل مرفوع دائماً." } ] }
```

### matching — التطابق

```json
{ "type": "matching", "marks": 3,
  "prompt": "صِل كل جملة بالصورة المناسبة.",
  "option_marker": "latin",
  "side_labels": ["الصور", "الجمل"],
  "layout": "auto",
  "options": [ { "image": "img/rain.svg" }, { "text": "نص" } ],
  "stems":   [ { "text": "It is raining." } ] }
```

- `options` الطرف المرمَّز بالحروف، و`stems` الطرف المرقَّم.
- `layout`: `auto` (الافتراضي) أو `horizontal` أو `vertical`.
- **اخلط ترتيب `options` بحيث لا يوافق ترتيب `stems`،** وإلا كشفت المحاذاة
  الإجابة.
- `img_height` يحدّ ارتفاع الصور، مثلاً `"70px"`.

### fill — إكمال الفراغ

```json
{ "type": "fill", "marks": 5,
  "prompt": "أكمل الفراغ بالكلمة المناسبة.",
  "bank": ["المطر", "الحديقة"],
  "bank_label": "بنك الكلمات",
  "items": [ { "text": "ينزل ______ في الشتاء." } ] }
```

ثلاث شُرَط سفلية فأكثر (`___`) تصير فراغاً منقّطاً. و`bank` اختياري.

### short — إجابة قصيرة

```json
{ "type": "short", "marks": 4, "lines": 2,
  "prompt": "أجب بإيجاز.",
  "items": [ { "text": "عرّف التبخر.", "lines": 3 } ] }
```

`lines` عدد الأسطر المنقّطة، على مستوى السؤال أو الفقرة.

### passage — قطعة قراءة

```json
{ "type": "passage", "marks": 5,
  "prompt": "اقرأ القطعة ثم أجب.",
  "passage": { "title": "الماء سر الحياة", "paragraphs": ["...", "..."] },
  "items": [
    { "text": "ما العنوان الآخر؟", "lines": 1 },
    { "text": "ما ضد (تجف)؟", "choices": ["تيبس", "ترتوي"] }
  ] }
```

فقرات القطعة مبرَّرة الطرفين، والفقرة الأقصر من ثلاثة أسطر تبقى بلا تبرير.
وللفقرة إما `choices` وإما `lines`.

### order — ترتيب الكلمات

```json
{ "type": "order", "marks": 2,
  "prompt": "رتّب الكلمات لتكوّن جملة مفيدة.",
  "items": [ { "text": "", "parts": ["إلى", "ذهب", "المدرسة", "محمد"] } ] }
```

### essay — إنشاء

```json
{ "type": "essay", "marks": 5, "lines": 8,
  "prompt": "اكتب فقرة من خمسة أسطر عن المحافظة على الماء.",
  "paragraphs": ["استعن بالأفكار التالية: ..."] }
```

## أخطاء يرفضها السكربت

- نوع سؤال غير معروف؛
- سؤال بلا `prompt`؛
- فقرة اختيار من متعدد بأقل من خيارين؛
- سؤال تطابق بلا `options` أو بلا `stems`؛
- نص بين `<` و`>` لم يُملأ (قالب نُسخ ولم يُحرَّر)؛
- صورة غير موجودة في المسار.

وتحذيرات لا توقف العمل: اختلاف مجموع الدرجات عن `total_marks`، واختلاف عدد
`options` عن عدد `stems`.
