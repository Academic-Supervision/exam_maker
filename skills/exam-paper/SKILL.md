# ورقة الاختبار

تحوّل هذه المهارة أسئلة الاختبار إلى ملف PDF مطبوع بهوية المدرسة: خط Tajawal،
والشعار، وألوان الشعار، في أربع صفحات على الأكثر.

**المحتوى ليس من عمل هذه المهارة.** الأسئلة ومستواها ومطابقتها للمنهج مسؤولية
المعلم أو المشرف. هنا الصياغة الشكلية والإخراج فقط.

## قواعد التخطيط التي تضمنها المهارة

| القاعدة | ما تفعله |
|---|---|
| توزيع أفقي متوازن | العناصر (صور، خيارات، بنك كلمات) تُوزَّع على أعمدة متساوية العرض، والصف الأخير الناقص يُتوسَّط فلا يبقى فراغ في طرف واحد |
| تناسق سؤال التطابق | الطرفان يأخذان التوزيع نفسه وعدد الأعمدة نفسه: إن كانت الصور أفقية صارت العبارات أفقية تحتها في الأعمدة ذاتها |
| السؤال لا ينقسم | كل سؤال كتلة واحدة لا تُقطع بين صفحتين، والتباعد يُضغط تدريجياً بدل ترك فراغ داخلي |
| تبرير هادئ | الفقرات مبرَّرة الطرفين، والسطر الأخير لا يُمطَّط، والفقرة الأقصر من ثلاثة أسطر تبقى بلا تبرير |
| الخيارات في سطر واحد | خيارات الاختيار من متعدد تُجمع في سطر واحد ما دامت تتسع، وإلا نزلت إلى عمودين أو ثلاثة متوازنة |
| حد الصفحات | الحد أربع صفحات؛ وإذا تعذّر بلوغه يتوقف السكربت عن الضغط ويطبع تنبيهاً واضحاً |

التفاصيل والأسباب في `references/layout-rules.md`.

## الخطوات

1. **اكتب ملف JSON** بالصيغة في `references/data-format.md`
   (مثال كامل يعمل: `references/example/exam-sample.json`).
2. **شغّل السكربت:**

   ```bash
   python skills/exam-paper/scripts/build_exam.py \
       --data exam.json \
       --out "اختبار_<المادة>_<الصف>.pdf"
   ```

   خيارات مفيدة: `--max-pages` (الافتراضي 4)، و`--html-out` لحفظ ملف HTML للفحص.
3. **اقرأ مخرجات السكربت.** يطبع عدد الصفحات، ودرجة التباعد المستعملة، وأكبر فراغ
   داخلي، وأي سؤال اضطر إلى الانقسام.
4. **انظر إلى الصفحات بعينك** قبل التسليم:

   ```bash
   pdftoppm -png -r 100 exam.pdf /tmp/pg
   ```

   ابحث عن نص مقصوص، أو صورة مشوهة، أو عبارة إنجليزية بعلامات في غير موضعها.
5. **سلّم الملف.** ولا تكتب شرحاً طويلاً بعده.

## حين تتجاوز الورقة أربع صفحات

يضغط السكربت التباعد على تسع درجات قبل أن يستسلم. إذا بقي العدد فوق الحد، طبع
تنبيهاً على `stderr` وأنهى العمل بالرمز 4، وفيه أطول الأسئلة.

**أبلغ المستخدم فوراً، ولا تقصّر محتوى الاختبار من عندك.** اعرض عليه:

- حذف فقرات من أطول الأسئلة (يسمّيها التنبيه)؛
- أو اختصار نصوص الفقرات؛
- أو نقل سؤال إلى ورقة ثانية؛
- أو رفع الحد صراحةً بـ `--max-pages`.

حذف سؤال أو تقصير قطعة قراءة قرارٌ تربوي يخص المعلم، لا قرار تنسيق.

> **ملاحظة على معنى «أربع أوراق»:** الحد المضبوط هو أربع **صفحات مطبوعة**. إن كان
> المقصود أربع ورقات على الوجهين فاستعمل `--max-pages 8`.

## الفحص

يُشغَّل تلقائياً بعد الإنشاء، ويمكن تشغيله وحده:

```bash
python skills/exam-paper/scripts/verify_exam_pdf.py exam.pdf exam.html --max-pages 4
```

يتحقق من: عدد الصفحات، وتضمين خط Tajawal دون خط احتياطي، ووسم الملف وعنوانه،
وسلامة طبقة النص (كل كلمة عربية وإنجليزية قابلة للنسخ والبحث، ووصلات لام-ألف
بترتيبها الصحيح)، وألّا يكون سؤال قد انقسم بين صفحتين، وتباين الألوان 4.5:1.

إذا فشل شيء فلا تسلّم الملف قبل معالجته، وأبلغ المستخدم بما تعذّر إصلاحه.

## أخطاء شائعة في كتابة البيانات

| الخطأ | الأثر |
|---|---|
| ترتيب `options` بترتيب `stems` نفسه في سؤال التطابق | الإجابة تظهر للطالب من المحاذاة. **اخلط الترتيب دائماً** |
| ترك `marks` فارغة | الدرجة الكلية لا تُحسب ولا تظهر في الترويسة |
| نص بين `<` و`>` لم يُملأ | السكربت يتوقف ويطلب كتابة النص الفعلي |
| صور كبيرة جداً | تُصغَّر تلقائياً، لكن ملف الـPDF يكبر؛ استعمل صوراً بعرض 600 بكسل فأقل |

## ملفات المهارة

- `scripts/build_exam.py`: المولّد (JSON ← HTML ← PDF عبر Chromium).
- `scripts/exam_css.py`: ورقة الأنماط وقواعد التخطيط.
- `scripts/fit.js`: القياس داخل الصفحة (توزيع الأعمدة، وتناسق التطابق، والتبرير).
- `scripts/verify_exam_pdf.py`: الفحص.
- `assets/fonts/`: خط Tajawal بأوزانه الأربعة مع الرخصة.
- `assets/logo.png`: شعار المدرسة.
- `references/data-format.md`: صيغة ملف البيانات وأنواع الأسئلة.
- `references/layout-rules.md`: قواعد التخطيط وأسبابها.
- `references/design-tokens.md`: الألوان والخط والهوامش.
- `references/example/`: مثال كامل بصور، يعمل كما هو.
